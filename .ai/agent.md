# 项目规范与重要事项

## 产品规则
1. **轻量化原则**：坚决不做重，不用下APP，优先考虑H5或微信小程序形态。
2. **聚焦核心**：解决同城/半熟人约局的核心问题——“三缺一”匹配与“信任/防鸽”机制。
## 架构演进
- MVP 阶段保持纯前端零服务器架构，通过 `LocalStorage` 本地持久化麻牌名片与履约信用分。
- 后续迭代路线：若需支持跨设备名声同步与多手机大厅实时线上拼局，优先采用免费极简 Serverless 数据库（如 Supabase / LeanCloud / Cloudflare D1）。

## AI 开发规范
- 直接给干货，不啰嗦，用简体中文。
- .ai 文件夹内所有文件必须为中文。
- todo.md 记录步骤，完成后打勾 `[x]` 并标注日期时间。
- 更新与迭代必须同步记录在根目录下的“更新日志.md”中，带时间、日期、版本号。
