# 项目背景：H5麻友，你在哪里

## 核心痛点
永远的“三缺一”；同城陌生人/半熟人约局时的“信任问题”和“防鸽子”。

## 产品基调
**轻便易传播**：绝对不能做重，免注册或极简注册，无需下载APP，依托微信生态（H5/小程序）和社交卡片分享。

## 潜在的三种核心信任机制（备忘记录，视阶段演进）

1. **绝对轻量的“开放广场模式”（主打流量和速度，适合 MVP 首发）**
   * **玩法**：用户一键发布“求组”或“缺人”，所有人都能看到附近的局。点击申请，房主看着顺眼（看眼缘或历史标签）就通过。
   * **优劣**：开发最快，门槛极低，容易起量；但爽约率偏高，依赖后期的标签互评机制（如“连续履约徽章”）。

2. **强力防鸽的“微押金/诚意金模式”（主打高质量局，适合跑通后商业化）**
   * **玩法**：报名上车需要支付微量“诚意金”（如 5-10 元）。打完原路退回，放鸽子则扣除补偿给其他人。
   * **优劣**：能极低爽约率，体验好；但涉及支付，前期劝退率高，需一定信任背书。

3. **2B2C的“棋牌室老板娘担保模式”（主打线下资源变现）**
   * **玩法**：仅认证的棋牌室能发局，老板娘作为中介担保并提供场地。
   * **优劣**：天然实体店背书，棋牌室有极强动力帮忙推广；但需线下地推搞定种子商户。

## MVP (V1.0) 核心业务主流程（基于“开放广场模式”）

### 流程一：局长极简发局（核心：快）
1. **进入平台**：点击“我要摇人”。
2. **填写局面**：填 4 个核心要素（玩法/底分、时间、目前差几人、地点信息）。
3. **生成诱饵**：生成带 H5 链接/二维码的“三缺一”海报或分享卡片。
4. **分发**：直接丢微信群/朋友圈，同时系统自动挂载到平台的“同城大厅”。

### 流程二：麻友上车（核心：阻力小）
1. **看到局**：通过群分享卡片直接进入，或在同城大厅刷到。
2. **点击上车**：点击“我要上车”。
3. **静默授权**：微信极简登录（头像昵称），状态变成“申请上车中...”。

### 流程三：局长审核与成局（核心：防奇葩）
1. **局长审核**：局长收到申请提醒，点击“同意”。
2. **联系方式交换**：同意后，双方可见微信号/虚拟电话，用于线下沟通。
3. **自动锁车**：人数补齐后，该局状态自动变为“已满发车”，后来者无法继续申请。

## MVP (V1.4) 深度体验与商业化演进方案（已批准）

1. **玩法标签**：四川血战/广东鸡平胡/红中换三张等多玩法标签与筛选。
2. **地图导航**：高德/腾讯地图 Web URI 一键路线规划调起 (`uri.amap.com`)。
3. **商户认证**：`🏪 官方认证棋牌室` 标识、环境实景图与大厅置顶展示。
4. **开局催发**：开局前 30 分钟到场确认与一键替换极速补位。
